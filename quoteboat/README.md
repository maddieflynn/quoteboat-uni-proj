# QuoteBoat Backend

Prior to running the QuoteBoat backend, ensure the following is installed:

- Visual Studio Code
- .NET SDK 

Open the folder in VS Code. 

Next, run the dependencies in the VS Code terminal:

dotnet restore

Then, run this command via the VS Code terminal:

dotnet run

The backend should open in a new browser window using the localhost port. It is recommended to run the backend first.
